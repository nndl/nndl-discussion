## 让问题更容易得到回答

提问前先搜索已有讨论。正文请写明书名与版本、章节或题号、你的理解和卡住的地方；涉及书稿时附页码与 PDF 下载日期，涉及代码时附运行环境、复现步骤和报错。

分享实践成果时，可以附上代码链接、实验设置、结果和自己的观察，方便其他读者复现与交流。
